# 共有 val で見ると、和集合は BioLIP 単独を上回らない (2026-09-13)

H7 (独立ラベル +54%) の CASF 評価はまだ走っているが、**学習の時点で
CASF に依存しない判定材料が 1 つ揃った** ので先に記録する。

3 コーパスは **byte 単位で同一の val 431 文書**を共有するよう作ってある
(`affprep` のガードが確認済み)。したがって最良 val loss は直接比較できる。

## 結果 (3 arm × 3 seed、全 9 run 完了)

| arm | 学習 docs | seed ごとの最良 val loss | 平均 | sd |
|---|---|---|---|---|
| `rot1` (BioLIP のみ) | 8,150 | 0.8378 / 0.8492 / 0.8536 | **0.8469** | 0.0080 |
| `union_clean` | 15,509 | 0.8094 / 0.8412 / 0.8941 | **0.8482** | 0.0429 |
| `pdbbind` 単独 | 7,359 | 1.0593 / 1.0338 / 1.0522 | **1.0484** | 0.0132 |

**和集合は BioLIP 単独と区別できない** (0.8482 対 0.8469)。
文書を +90%、独立な複合体を +54% 増やして、**held-out 損失は動かなかった。**

さらに **和集合は seed 分散が 5 倍**になる (sd 0.043 対 0.008)。
データを増やして安定化するどころか、逆に振れ幅が広がった。

**PDBbind 単独は明確に悪い** (1.048、全 3 seed で 1.03–1.06)。
BioLIP 単独より 0.20 悪く、seed 間は安定しているので偶然ではない。
同じ Kd/Ki ラベル、同じ件数規模で、**ソースによってこれだけ差が出る**。

## 何が言えて、何が言えないか

- **言える**: 共有 val 上では、独立ラベルを 54% 足しても損失は改善しない。
  これは CASF に依存しない測定である。
- **言える**: PDBbind のラベル/ポケット構築は、この用途では BioLIP より劣る。
  7 月に「PDBbind は BioLIP と同等」と結論したが、**同等ではない**
  (当時は単一 run の比較だった)。
- **言えない**: CASF の scoring R / ranking ρ がどうなるかは、これでは決まらない。
  val loss は smooth-L1 の平均であり、**相関指標とは別物**である。
  実際 H1 (フレーム平均) は val loss を一切変えずに R を +0.010 動かした。
  **CASF の評価を待つこと。**
