# 親和性の推論はフレーム平均を一度もしていなかった (2026-09-13)

事前登録: `docs/notes/2026-09-13_affinity_prereg.md` の H1。
ベンチ: `benchmarks/affinity-bench`、CASF-2016 の 285 複合体。

## 何を測ったか

ポケット正準フレームはポケットから導かれるので、複合体の親和性がその向きに
依存する理由は無い。**しかし量子化があるので依存する。** ポーズ側では、この
フレーム間のばらつきが予測 RMSD で σ≈0.32 Å あり、top-1 を決める差 0.05 Å より
大きいことが分かっていて、推論時に 16 回の回転で平均している (論文 Method に
記載済み)。

**親和性側には同じ機構が無かった。** `RescoringConfig` には `n_frames` があるが
`AffinityConfig` には無く、公表値はすべて 1 フレームで測られている。
このノイズは複合体ごとに独立で pK とは無相関なので、Pearson R と クラスタ内
Spearman の**両方**を 0 方向に引く。

## 結果 (既存ヘッド `tzqaubl4`、再学習なし)

| n_frames | scoring R | ranking ρ |
|---|---|---|
| 1 (対照) | 0.7711 | 0.6474 |
| 4 (診断) | 0.7862 | 0.6474 |
| **16 (報告値)** | **0.7816** | **0.6772** |
| GenScore | 0.8159 | 0.7351 |

- n_frames 1 は公表 dump を**ビット単位で再現**した (同じ GPU 上)。移植の検証も兼ねる。
- **16 で R +0.0105 / ρ +0.0298**。事前登録した「外れ」の閾値 (両指標とも +0.005 未満)
  を両方とも超えたので、**H1 は成立**。
- GenScore との差は (−0.045, −0.088) → (−0.034, −0.058)。
  **scoring の p が 0.044 → 0.114 に動き、単一モデルが「有意に負け」でなくなった。**

## 4 フレームの ρ が対照とぴったり一致した件

偶然だった。57 クラスタ中 36 で ρ が変化し、変化量の和がちょうど 0 になっている
(予測値自体は 285 件すべてで違い、中央値 |Δ| = 0.22)。5 点の Spearman は 0.05 刻みの
離散値しか取らないので、この一致は起こりうる。**不具合ではない。**

読み方としては、k=4 では平均化がまだ足りず ρ が動かない、が正しい。R は k=4 の方が
高いが、**報告するのは事前に決めた k=16 である**。3 点から最良を選ぶことはしない。

## 効いた理由と、効かなかった場所

これは表現を良くしていない。**測定からノイズを取り除いただけ**で、そのノイズは
最初から我々の側にしか無かった (GenScore も Boltz-2 も連続座標で動くのでフレームを
持たない)。つまりこれは**公平性の修正**であって、モデルの改善ではない。
残る差 (−0.034, −0.058) が本当のモデル差ということになる。

## seed 依存性 (3 seed)

16 フレームはどの向きを引くかで変わるので、seed 0/1/2 で測り直した。

| | scoring R | ranking ρ |
|---|---|---|
| 1 フレーム | 0.7711 | 0.6474 |
| 16 フレーム seed 0 | 0.7816 | 0.6772 |
| 16 フレーム seed 1 | 0.7795 | 0.6754 |
| 16 フレーム seed 2 | 0.7818 | 0.6684 |
| **16 フレーム 平均 ± sd** | **0.7810 ± 0.0013** | **0.6737 ± 0.0046** |

**seed 間のばらつきは改善幅より一桁小さい** (R: ±0.0013 対 +0.0099、
ρ: ±0.0046 対 +0.0263)。運ではない。

報告する値は事前登録どおり **seed 0 の 0.7816 / 0.6772**。平均を報告値にすると
3 回引いた分だけ有利になるので、最初に引いた 1 本を使う。

学習 seed の分散 (R sd 0.050) が入らない。
