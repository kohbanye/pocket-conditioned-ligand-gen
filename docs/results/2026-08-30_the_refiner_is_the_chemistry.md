# 化学的な質の崩壊は、ぜんぶリファイナがやっている

2026-08-30。94 標的でペア比較（デコーダ・LM は同一、リファイナだけを替える）。

## 1. 結合長の崩れは、デコーダではなくリファイナが作っている

`>0.15 A` 逸脱している結合の割合（結晶 4.5% / FLOWR 5.2% が基準）:

| 構成 | 逸脱率 | vina score | PB valid | strain |
|---|---|---|---|---|
| リファイナ無し | **8.1%** | +5.79 | 1.00 | 207 |
| + geom_lb10 | 21.5% | +1.10 | 1.00 | 217 |
| + new_lb10 | 34.0% | −0.04 | 1.00 | 396 |
| + press0.6（配備中） | **48.2%** | −1.12 | **0.00** | 698 |
| FLOWR | 5.2% | −5.70 | 1.00 | 47 |

ペア Wilcoxon: リファイナ無し → press0.6 で **+38.2 pt (p=3.8e-17)**。

**デコーダ単独の化学は 8.1% で、FLOWR の 5.2% とほぼ並んでいる。**
これまで「ProLIT は 48.1%」と書いてきた数字は、デコーダの性能ではなく
リファイナが壊した後の数字だった。

## 2. リファイナ族はひとつのトレードオフ直線に乗っている

上の表は単調である。**結合を壊すほど vina score が良くなる**（約 0.17 kcal / 1 pt）。
リファイナは「良いポーズ」を学んだのではなく、**分子を潰して反発項を消している**。
FLOWR はこの直線の上にいない（5.2% で −5.70）。
**この軸をどれだけ調整しても FLOWR には届かない。**

## 3. リファイナは分子そのものを書き換えている

同一シード・同一 (target, idx) で 9836 分子を突き合わせた（原子数一致 98.4%）:

- **SMILES が変わった分子 52.2%**（press0.6）、37.0%（geom_lb10）
- 変わった側は dock −8.00 と**もともと強い**分子。大きい分子ほど壊される。

結合は座標から知覚しているので、座標を 0.45 A 動かせば分子が変わる。
つまり **ベンチが採点している分子は、LM が生成した分子ではない。**
SMILES 由来の指標（novelty / diversity / QED / SA）も同じ影響を受けている。

## 4. デコーダ再学習パイロットの決着

`--freeze-encoder --weight bond12=60 --weight clash=15`（4 pt）:

| | リファイナ無し | press0.6 あり |
|---|---|---|
| 配備デコーダ | 8.1% | 48.2% |
| 再学習デコーダ | **6.1%** | 48.4% |
| ペア p | 1.8e-13 | 1.1e-03 |

**再学習は効いている（−1.67 pt, p<1e-12）が、リファイナが完全に覆い隠す。**
損失重み付けの効果はリファイナの破壊の 1/23 でしかない。
→ **VQ 全体再学習（~78 pt）に進む根拠にはならない。パイロット 4 pt が 78 pt を止めた。**

（前回「再学習は配備構成で効果が無い」と書いたのは対照の取り違えだった。
`gen_geom_ml` は別のリファイナを使っており、同一リファイナの対照は `gen_t07_ml`。）
