# モデルは学習データにあるより強いサイズ依存を作っている (2026-09-13)

`2026-09-13_the_size_bias_replicates_out_of_casf.md` の続き。
サイズ依存は「本物の信号に乗りすぎ」だと書いてきたが、**乗りすぎどころではなかった。**

## 学習データのサイズ–pK 結合を測る

全原子トークナイザは **1 重原子 = 1 トークン**なので、
学習コーパスからリガンドの重原子数を直接復元でき、pK ラベルと突き合わせられる
(各コーパス 6,000 文書をサンプル):

| コーパス | 学習 docs | 重原子 平均 | **corr(重原子, pK)** |
|---|---|---|---|
| `e250aff_r1` (BioLIP) | 8,150 | 25.8 | **+0.356** |
| `e250aff_union_clean` | 15,509 | 28.1 | **+0.229** |
| `e250aff_pdbbind_clean` | 7,359 | 30.6 | **+0.170** |

## 予測のサイズ依存はその倍近い

| | corr(重原子, 実測 pK) | **corr(重原子, 予測)** |
|---|---|---|
| CASF (285) | +0.500 | **+0.665** |
| PDBbind holdout (281) | +0.353 | **+0.620** |

**学習ラベルが支えているのは +0.356 なのに、予測は +0.62〜+0.67 で動く。**
評価セットの真の結合 (+0.35〜+0.50) と比べても強い。
**モデルは、自分の学習データにある以上のサイズ依存を作り出している。**

## どこから来るのか — 表現の中でサイズが突出している

同じ凍結表現の線形プローブ (標的単位 CV) で読み出せる量を並べると:

| 読み出す対象 | r |
|---|---|
| **重原子数** | **+0.926** |
| ポケット残基数 | +0.744 |
| 水素結合数 / 原子 | +0.764 |
| 接触数 | +0.717 |
| **実測 pK** | **+0.468** |

**サイズは表現の中で最も読み出しやすい量**であり、pK の 2 倍近く読める。
pK を当てようとするヘッドにとって、**最も強く最も取り出しやすい相関がサイズ**である。
乗るのは自然で、乗りすぎるのも自然である。

## ただし、これがそのまま「直せる欠陥」だとは言えない

**既に測ってある反証**: 学習済み予測をサイズ成分とサイズ非依存成分に分け、
**test 上で最適に重み付け直しても R は +0.0005 しか増えない**
(`2026-09-13_all_three_candidates_are_dead.md`)。
サイズの重みが真に過大なら、重みを直せば改善するはずである。しないということは:

- **(a)** 増幅は症状であって損失の原因ではない
  (本体はサイズ非依存成分の弱さ: 偏相関 0.698 対 GenScore 0.772)、あるいは
- **(b)** 害は出力より上流で生じており、出力のスケール調整では戻せない
  (ヘッドが学習中にサイズに引きずられ、サイズ非依存の信号を学び損ねている)

**この 2 つを今回の測定は区別していない。** (a) なら打つ手はここには無い。
(b) なら**表現からサイズ方向を抜いてからヘッドを学習させる**のが対応する介入で、
これは出力の再重み付けとは別物であり、**まだ試していない**。

## 決着: (a) だった — サイズは正味で有益

表現からサイズ方向を**反復射影**で抜きながら、pK 予測を各段階で測った
(標的単位 5-fold CV、n=285)。

最初に単発の射影で試したときは、対照 (重原子数の読み出し) が 0.926 → 0.844 に
しか落ちず、**サイズが多数の方向に冗長に載っている**ことが分かった。
つまり単発射影では**除去できていない**ので、そのときの「ほぼ不変」は
判定として使えなかった (道具が効いていないだけだった)。反復に切り替えた:

| 反復 | pK の r | 重原子の r (対照) | corr(重原子, 予測) |
|---|---|---|---|
| 0 | **0.4678** | 0.926 | +0.702 |
| 3 | 0.4489 | 0.799 | +0.651 |
| 6 | 0.4306 | 0.751 | +0.603 |
| 9 | 0.4082 | 0.679 | +0.545 |
| **12** | **0.3577** | **0.566** | +0.443 |

**サイズを抜くほど pK 予測は単調に下がる** (0.468 → 0.358)。
対照が 0.926 → 0.566 と崩れているので、今度は除去が効いている。

→ **(a) が正しい。サイズは正味で有益であり、増幅は症状であって原因ではない。**

これは再重み付けの天井 (+0.0005) と整合する。どちらも
**「サイズ channel に損失は住んでいない」**と言っている。

### したがって、直前に提案した介入は却下

「表現からサイズ方向を抜いてからヘッドを学習させる」は**やってはいけない**。
測った限り、それは pK 予測を 0.11 悪化させる方向である。
7 月の efficiency 学習 (pK を重原子数で割る) が失敗したのと、根は同じ
——**サイズを取り除く方向の介入は、有益な信号を捨てている。**

## (参考) 当初書いた「次に測るべき 1 つ」

**(a) と (b) を分ける実験**: 表現からサイズ方向を射影で除去し、
その上でプローブ/ヘッドを学習して pK 予測が上がるか下がるかを見る。

- 下がる → サイズは正味で有益、(a)。増幅は無害な症状。
- 上がる → サイズがサイズ非依存の学習を阻害していた、(b)。
  **7 月の efficiency 学習 (pK を重原子数で割る) が失敗したのとは別の介入**で、
  あれは目的変数を変えたが、これは入力から方向を抜く。

注: 単純な射影は情報も落とす (サイズは真に +0.35〜0.50 相関する) ので、
**素朴にやれば下がるのが既定**。上がったときだけ意味がある。
