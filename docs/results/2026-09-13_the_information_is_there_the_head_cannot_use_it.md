## 1. 極性の情報は MLM 表現に入っている (十分すぎるほど)

凍結した `mlm_e250lig3` の mean-pool 表現 (768 次元、CASF 285) から、
**標的単位 5-fold CV の線形プローブ**で界面量を読み出せるか:

| 読み出す対象 | 相関 |
|---|---|
| **水素結合数 / 原子** | **+0.764** |
| **水素結合数** | **+0.722** |
| 接触に占める極性の割合 | +0.619 |
| 荷電接触数 | +0.584 |
| 疎水接触数 | +0.690 |
| 疎水接触数 / 原子 | +0.487 |
| 埋没率 | +0.622 |
| (対照) 重原子数 | +0.926 |
| (対照) ポケット残基数 | +0.744 |
| **実測 pK** | **+0.469** |

**極性側は疎水側より *よく* 読める** (0.764 対 0.487)。
→ **「MLM が極性相互作用を表現に載せていない」は否定された。**

量子化も否定済み (前掲)。**つまり情報はトークンにもあり、表現にもある。
足りないのは、それを pK に変える読み出しの側である。**

決定的な数字: **凍結表現の線形プローブが pK を +0.469 でしか読めない**のに、
同じ表現を fine-tune したヘッドは 0.78 を出す。つまり fine-tune が大きく引き出して
いる一方で、**界面量そのものは線形でも 0.72〜0.76 読める**。
情報の存在と、それが pK に変換されているかは別問題である。

## 2. 誤差の 94% は seed によらない — 私の朝の説明は間違っていた

3 seed の**誤差パターン**の相関:

| | |
|---|---|
| seed7 対 seed11 | +0.963 |
| seed7 対 seed12 | +0.905 |
| seed11 対 seed12 | +0.922 |
| **平均** | **+0.930** |

分散分解: 共通成分 2.068 / seed 固有成分 0.122 → **誤差の分散の 94% が共通**。

**訂正**: 本日午前に「予測のばらつきの 32% が seed 由来」「単一 run の ρ は
ほとんどノイズを見ている」と報告した。**前者は予測について正しく、後者の含意は
誤りだった。** 誤差で測ると共通成分が圧倒的で、**モデルは毎回ほぼ同じ場所で
同じように外している**。seed 平均が効いたのは、大きな固定誤差の上に乗った
小さなノイズを削ったからであって、別のモデルが現れたからではない。

ranking ρ が seed 平均で GenScore に並ぶという事実自体は変わらない。
しかし「差はノイズだった」という説明は**強すぎた**。正しくは
「小さなノイズ項を削れば並ぶが、誤差の本体は共通で残っている」。

## 3. 共通誤差は極性とも相関しない

| 共通誤差との相関 | |

## 次に測るべきこと

界面量が線形で 0.72〜0.76 読めるのに pK が 0.47 しか読めないなら、
**pK は界面量の単純な関数ではない**。そこで:

1. 界面量 (H結合数・疎水接触・埋没率…) を**説明変数として直接与えた**線形モデルで
   pK がどこまで行くか。これが「情報を完全に使えたときの天井」の下限になる。
2. 表現 + 界面量 を両方与えたときに天井が上がるか。上がるなら、
   表現には入っているが**ヘッドが取り出せていない**ことの直接証拠になる。
