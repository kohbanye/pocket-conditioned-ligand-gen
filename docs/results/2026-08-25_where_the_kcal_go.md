# 5 kcal/mol はどこで失われるか (2026-08-25)

**同じ 100 個の参照リガンド**を、段を 1 つずつ足しながら同じ評価器で採点した。
分子は全段で不変なので、差はポーズだけ。

| 段 | Vina score | 結晶からの累積損 | **その段の損** | RMSD |

## 読み方

**トークナイザは 1.28 kcal/mol、LM のコード選択は 3.81 kcal/mol。
LM の方が 3 倍高い。**

そして **FLOWR (-5.73) は VQ 往復 (-5.60) のすぐ隣にいる**。つまり:

> **LM がエンコーダと同じ精度でコードを選べていれば、ProLIT は -5.60 で
> FLOWR (-5.73) とほぼ並び、リファイナを足した -5.86 なら上回る。**

トークナイザは FLOWR 越えを妨げていない (`2026-08-23_tokenizer_ceiling.md` の
訂正と一致)。**全部 LM のコード選択にある。**

LM は teacher forcing でもコードの **44.9% しか完全一致しない**。
外し方は幾何的で、化学ではない (element 0.975 / charge 1.000 / aromatic 0.960 /
numH 0.962 の一致率)。だから分子は正しく、置き場所と形だけが違う。

## これで説明がつくこと

- **dock が互角** (FLOWR との差 -0.07、p=0.68): 分子は足りている。
- **リファイナで戻せない**: 誤差は「別のコードを選んだ結果」で、
  (壊れたポーズ, ポケット) の中に正解が残っていない。
- **芳香性・QED・PB-validity が悪い**: 分子の同一性は座標から距離で
  読み出されるので、2.5 A ずれれば別の分子になる
  (`2026-08-25_the_chemistry_is_a_readout_of_the_coordinates.md`)。
- **押し出し腐敗が Vina を買う**: 衝突を外すのは効くが、ポーズは戻らない。

## 残る打ち手は LM 側だけ

潰れたもの: checkpoint 差し替え / 追加 finetune / 幾何平滑化 CE /
CLM 腐敗コーパスのリファイナ / 剛体フィット / 学習した結合ヘッド。

**まだ試していない、根拠のあるもの**:

配備 LM (`clm_e250lig3_fullft`) の val loss は
**epoch 0 で 5.3568、epoch 1 で 5.4648 と悪化**して early stop している。
4.1B トークンのコーパスに対して 298M のモデルが 1 epoch で過学習することは
考えにくく、**lr 3e-4 が高すぎた**とみるのが自然。
学習率を下げて fullft 段をやり直せば、コード選択そのものが良くなる可能性がある。
これが「源流を直す」最後の具体案。

サンプリング温度を下げるのは**この表の最後の 1.6 kcal**を取りに行く話で、
天井 (-5.60) には届かない。多様性と引き換えなので、
uniqueness を並べて報告する (`docs/notes/2026-08-25_temperature_prereg.md`)。
