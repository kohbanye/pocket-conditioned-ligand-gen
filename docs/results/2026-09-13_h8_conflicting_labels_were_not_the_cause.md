# H8: 矛盾ラベルは union の ranking 低下の原因ではなかった (2026-09-13)

事前登録: `docs/notes/2026-09-13_affinity_prereg.md` の H8。
**対照は `e250_union_clean`** (rot1 ではない)。判定は `n_better`/3。

## コーパス

BioLIP と PDBbind が **|Δ|>1.0 log で矛盾する pK** を与えている 151 件を
PDBbind 側から除外して作り直した。

| | train docs | 除外 |
|---|---|---|
| `union_clean` (H7) | 15,509 | holdout 259 |
| `union_noconf` (H8) | **15,351** | holdout 259 + 矛盾 ~147 (計 406) |

val はどちらも同じ 431 文書 (byte 一致、prep のガードが確認済み)。

## 結果

| seed | union R | noconf R | union ρ | noconf ρ |
|---|---|---|---|---|
| 7 | 0.7877 | **0.8096** | 0.6368 | **0.7158** |
| 11 | 0.7880 | 0.7836 | 0.6719 | 0.6509 |
| 12 | 0.7930 | 0.7980 | 0.6807 | 0.6789 |

| 家系 | scoring R | ranking ρ |
|---|---|---|
| `e250_union_clean` | 0.7896 ± **0.0030** | 0.6632 ± 0.0232 |
| `e250_union_noconf` | 0.7971 ± 0.0131 | 0.6819 ± 0.0326 |
| GenScore | 0.8159 | 0.7351 |

**判定**: scoring Δ+0.0075 で **2 / 3**、ranking Δ+0.0187 で **1 / 3**。
**どちらも 3/3 に届かない。H8 は成立しない。**

## 唯一の ranking 勝ちは、また平均への回帰

ρ が上がったのは seed 7 だけ (0.6368 → 0.7158、+0.079)。
**seed 7 は union の 3 seed 中 ρ が最も低い引き**である。
seed 11 は −0.021、seed 12 は −0.002 と下がっている。

**H9 で全く同じ形を指摘したばかりである** (listwise の唯一の ρ 勝ちも、
union で最も ρ が低い seed 7 だった)。**結果が自分に都合が良いからといって
読み方を変えない。** 最も弱い出発点でだけ改善が出るのは効果の形ではない。

## したがって事前登録どおりの結論

事前登録にこう書いてある:

> **外れ**: ranking が上がらない。その場合、union の ranking 低下は
> 矛盾ラベルのせいではなく、**PDBbind データの ranking 品質そのもの
> (単独で ρ 0.6345) が混合物に漏れているため**、と確定する。

ranking は 1/3 なので、**矛盾ラベル説は棄却**し、
**PDBbind の ranking 品質が混合物に漏れている**を採る。
これは `2026-09-13_pdbbind_alone_loses_to_biolip.md` と整合する
(PDBbind 単独は ranking 0/3 で負け、共有 val でも 0.20 悪い)。

## 副次: 分散の縮小は脆い

| | scoring sd | ranking sd |
|---|---|---|
| `union_clean` | **0.0030** | 0.0232 |
| `union_noconf` | 0.0131 (4.4 倍) | 0.0326 (1.4 倍) |

**158 文書 (1%) 抜いただけで、17 倍の分散縮小が 4 分の 1 失われた。**
H9 の listwise も同じものを壊した (9 倍悪化)。
**union_clean の最大の長所は、コーパスにも損失にも敏感で脆い。**
再現するなら構成を正確に保つこと。

## 参考: 今夜の clean な単一モデル最良

`union_noconf` seed 7 = **R 0.8096 / ρ 0.7158** (GenScore 0.8159 / 0.7351)。
**汚染を除いた単一モデルとしては今夜の最良**だが、
**家系平均 0.7971 / 0.6819 からの 1 本の引き**であって再現性のある構成ではない。
sd 0.0131 / 0.0326 を考えれば、この seed を選んで報告するのは test 上の選択になる。
