## 判定: 成立しない (事前登録の結果 3)

**どちらの指標も 3/3 に届かない。** 事前登録した 3 つの読み方のうち、
「**どちらも 3/3 でない → H7 も外れ**」に該当する。

**目標も未達**: 単一モデルで R>0.8159 かつ ρ>0.7351 を要求しているが、
union の最良 seed でも **0.7930 / 0.6807**。

## ただし分散は本当に崩れた (事前登録済みの副次指標)

事前登録に「**平均が動かなくても分散は別に報告する**」と書いた。報告する:

| | per-seed R | sd |
|---|---|---|
| `rot1` | 0.7957 / 0.7694 / 0.6981 | **0.0505** |
| `union_clean` | 0.7877 / 0.7880 / 0.7930 | **0.0030** |

**17 倍の縮小。** union の scoring はほぼ決定論的で、どの seed を引いても 0.788–0.793。
汚染版でも ~9 倍の縮小が見えており、**leak の産物ではない**
(事前登録では「残らなければ leak の産物と結論する」と書いていた —— 残った)。

**これが `n_better` が 2/3 に留まった理由でもある**: rot1 の seed 7 (0.7957) は
rot1 自身の最良の引きで、それが「ほぼ動かない union」を 1 回だけ上回った。
平均は union が +0.035 上だが、対比較は rot1 の分散に支配されている。

## 3 つの腕は整合している

`union = rot1 ∪ pdbbind` であり、**pdbbind 単独は ranking が最も悪い** (0.6345)。

- scoring: pdbbind を混ぜると **上がる** (0.754 → 0.790)
- ranking: pdbbind を混ぜると **下がる** (0.695 → 0.663)

**PDBbind のデータは大域較正を助けるが、クラスタ内の識別を悪化させる。**
ソース単独の性質 (ρ 0.635) がそのまま混合物に漏れている。

## 実務上の含意

論文の主系統は「単一モデル・既定ハイパラ」である。その観点では:

- **`union_clean` は再現性で圧倒的に有利**。どの seed でも R≈0.789 が出る。
  `rot1` は 0.70–0.80 を引く賭けになる。
- **しかし ranking は `rot1` の方が良い** (0.695 対 0.663)。
- **どちらも GenScore には届かない。**
