# 正典 100 ポケットでの生成 (2026-08-22)

**標的セットを作り直した後の、初めて他手法と同一入力で並べられる数値。**
それまでの「97 標的」は CrossDocked の標準テスト分割ではなかった
(`docs/notes/2026-08-21_target_set_was_not_the_canonical_split.md`)。

構成: CLM `clm_e250lig3_fullft` e00 + refiner `refit_e250lig3` e16。
デコード側に place-before-refine / 価数剪定 / 断片接合 / 芳香性ヘッドの利用、
後処理に分子ごとの拘束半径での局所緩和 + 剛体 + torsion 沈み込み。

## 公平性

**FLOWR の 0.92 は後処理なしの値**。同条件で並べるなら我々の生の行と比べる:

| | PB | clash-free |
|---|---|---|
| 生 (place-first なし) | 0.632 | 0.246 |
| 生 (place-first あり) | 0.661 | 0.611 |
| 後処理 (place-first なし) | 0.949 | 0.945 |
| 後処理 (place-first あり) | 0.953 | 0.944 |

(25 標的・622 分子の抜き取り)

**PB 0.93 は後処理込みの値であり、FLOWR の 0.92 と同条件ではない。**
表には raw / +relax / +relax+rigid+torsion を別行で出すこと。

place-first の価値は**生の行にある** (clash-free 0.246 -> 0.611)。後処理を
かけると差はほぼ消える (0.949 対 0.953) ので、後処理が同じ欠陥を別経路で
直しているということ。

## Vina score が届かない理由は分子の質

参照リガンドの Vina score は -6.81 で、**FLOWR の -6.29 は結晶リガンドに近い
水準**。つまり 4.6 kcal/mol の差は「ポーズがずれている」ではなく
「分子として結合が弱い」。

その原因は特定済み (`docs/notes/2026-08-21_aromatic_head_collapsed.md`):
トークナイザの芳香性ヘッドが再現率 0.014 で崩壊しており、生成分子は
fsp3 中央値 1.00 (参照 0.50)、芳香環 0.77/分子 (参照 1.31)。環の数は
vina_min と最も強く相関する特徴 (Spearman -0.241)。

ポーズ側はもう出し切っている: 剛体 + torsion で clash-free 0.963、
score - min の差は 2.86 まで縮んだが、そこから先は立体だけの目的関数では
届かない (Vina の疎水項・水素結合項)。

## 論文に向けて足りないもの

- **FLOWR の完全な公表表**。手元にあるのは PB と Vina score の 2 つだけで、
  「ほとんどの指標で勝つ」を判定できない。
- 芳香性ヘッドの修正 (source ごとの制約 + クラス均衡)。デコーダ単独で
  直せることは確認済み (コード 100/100 一致) だが、制約がプールされている
  のを直すまでは効かない。
