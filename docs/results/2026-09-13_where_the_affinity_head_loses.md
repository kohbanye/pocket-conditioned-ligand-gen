# 親和性でどこを負けているか — 層別診断 (2026-09-13)

> **⚠️ この文書の「必要な改善」は、同日夜の測定で全部否定されている。**
> ここで挙げた原因候補 (極性相互作用の質 / 微細幾何の量子化損失) は、
> どちらも直接測って**否定された**。最新の到達点と何が残っているかは
> **`2026-09-13_all_three_candidates_are_dead.md`** を読むこと。
>
> 本文のうち**有効なのは層別の事実**: サイズへの寄りかかり (corr 0.665 対
> 真の関係 0.500)、再重み付けの天井が +0.0005、系統群 188/285 が誤差の 87% を
> 占めること、記述子の null 群。**外れたのは §4 §5 と「必要な改善」の中身。**

対象: `e250_rot1` (e250 トークナイザ + 素の pK 回帰 + 単一 mean-pool ヘッド)、
CASF-2016 285 複合体、n_frames 16。
**予測は 3 学習 seed の平均を使った。** これは報告値ではなく**診断の道具**で、
seed ノイズ (R sd 0.05) を落とさないと系統成分が見えないため。

per-complex / per-cluster の CSV: `2026-09-13_affinity_per_complex.csv` / `_per_cluster.csv`。

## 結論を先に

**負けは 1 種類ではなく 2 種類で、原因も対策も別。**
そして **2 種類目の「中身」は、285 複合体では特定しきれなかった** (§4, §5)。

| 指標 | 差 | 正体 |
|---|---|---|
| **ranking ρ** | 0.7351 対 0.7351 | **差は無い。単一 run のノイズだった** |
| **scoring R** | 0.784 対 0.816 | **本物。リガンドの大きさに寄りかかっている** |

## 1. ranking の負けは、モデルの欠陥ではなく学習ノイズだった

同じ重みの読み出しを変えず、seed だけ変えた 3 本と、その平均:

| | scoring R | ranking ρ |
|---|---|---|
| seed 7 | 0.7957 | 0.7175 |
| seed 11 | 0.7694 | 0.7228 |
| seed 12 | 0.6981 | 0.6456 |
| **3 seed 平均** | 0.7842 | **0.7351** |
| GenScore | 0.8159 | **0.7351** |

**平均を取ると ρ は GenScore とぴったり並ぶ。** つまり系統的な順位付け能力は
既に同等で、**単一 run の ρ 0.65〜0.72 は系統成分ではなくノイズを見ていた**。

機序も数字で追える:

- 複合体あたりの予測の seed 間 sd = **0.379**（中央値 0.355、最大 1.04）
- 我々の予測全体の sd = 1.200 → **予測のばらつきの 32% が seed 由来**
- クラスタは 5 リガンドで pK 幅が 3 以上のものが 48/57。つまり
  **隣り合うリガンドの間隔は概ね 0.75 log**
- **ノイズ 0.379 は、区別すべき間隔 0.75 の半分**。順位が入れ替わって当然

`corr(seed_sd, |err|) = +0.127` と弱いので、**ノイズは特定の複合体に偏っていない**。
一様に乗っている。

## 2. scoring の負けは本物 — サイズへの寄りかかり

| | corr(重原子数, 予測) |
|---|---|
| **真の関係** corr(重原子数, 実測 pK) | **+0.500** |
| **我々** | **+0.665** ← 真の関係より強い |
| Boltz-2 | +0.550 |
| GenScore | +0.415 |

**我々はサイズを、実際の pK との関係よりも強く使っている。** GenScore は逆に
控えめに使っている。サイズだけの予測器でも R=0.500 出るので、
「大きい分子はよく効く」は本物の信号ではあるが、我々はそれに乗りすぎている。

サイズを偏相関で除くと、残る信号量がはっきり分かれる:

| | corr(予測, pK | 重原子数) |
|---|---|
| GenScore | **0.772** |
| 我々 | **0.698** |
| Boltz-2 | 0.661 |

**サイズを除いた後の信号が GenScore より 0.074 少ない。これが scoring の差の正体。**

### 予測レンジの圧縮

- 実測 pK: sd 2.17、範囲 [2.07, 11.82]
- 我々: sd 1.20、範囲 [3.84, 9.34]、**回帰の傾き 0.433**

pK 帯ごとのバイアスは完全に単調で、平均への回帰そのもの:

| pK 帯 | <4 | 4-5 | 5-6 | 6-7 | 7-8 | 8-9 | >9 |
|---|---|---|---|---|---|---|---|
| バイアス | **+2.16** | +1.37 | +0.85 | +0.31 | −0.28 | −0.83 | **−1.88** |

**ただし圧縮自体は R も ρ も下げない**（どちらも単調変換・尺度変換に不変）。
圧縮は症状であって原因ではない。原因は「弱い結合を弱いと言えない」こと。

### 一番負けている複合体が語っていること

| pdbid | 実測 | 我々 | 重原子 | 形 |
|---|---|---|---|---|
| 3zsx | 3.28 | 6.86 | 34 | 大きくて弱い → 過大評価 |
| 4cig | 3.67 | 7.11 | 37 | 同上 |
| 3zt2 | 2.84 | 6.00 | 23 | 同上 |
| 3bv9 | 5.36 | 8.14 | 47 | 同上 |
| 3f3e | **7.70** | **5.50** | **9** | **小さくて強い → 過小評価** |
| 3f3c | 6.02 | 4.87 | 13 | 同上 |
| 4pcs | 7.85 | 6.18 | 16 | 同上 |
| 3uuo | 7.96 | 6.17 | 23 | 同上 |

**両端がきれいに割れている。** 大きくて弱い分子を過大に、小さくて強い分子
(フラグメント様の高効率結合) を過小に評価する。サイズ依存の直接の帰結。

## 3. 較正の問題ではない — 信号が足りない (決定的)

「サイズに寄りかかっている」なら、サイズ成分とサイズ非依存成分の**重みを付け直せば
直る**はずである。それを test 上で最適化して天井を測った（重みを test に当てているので
これは「方法」ではなく「再較正で到達しうる上限」）:

| 手法 | 現状 R | 再重み付けの天井 | 得られる分 |
|---|---|---|---|
| **我々** | 0.7842 | 0.7847 | **+0.0005** |
| GenScore | 0.8159 | 0.8351 | +0.0192 |
| Boltz-2 | 0.7532 | 0.7602 | +0.0070 |

**我々には再較正の余地がゼロ。** 既に最適な重みで混ざっている。
皮肉なことに、余地があるのは GenScore の方 (+0.019)。

成分を入れ替えると原因がはっきりする:

| 構成 | R |
|---|---|
| 我々のサイズ成分 + **我々の**サイズ非依存成分 | 0.7846 |
| 我々のサイズ成分 + **GenScore の**サイズ非依存成分 | **0.8351** |

| | サイズ成分のみ | サイズ非依存成分のみ |
|---|---|---|
| 我々 | R=0.500 | R=**0.604** |
| GenScore | R=0.500 | R=**0.669** |

サイズ成分は両者まったく同じ (当然、同じ変数から作っている)。
**差は 100% サイズ非依存成分の質。** 2 つの残差の相関は 0.716 なので、
同じものを見ている部分は大きいが、GenScore はそれ以外を余分に持っている。

→ **efficiency 学習 (pK/重原子数) のような「サイズを罰する」手は原理的に効かない。**
   重み付けの問題ではないので、直す対象がそこに無い。7 月に efficiency で
   scoring が崩れたのは偶然ではなく必然だった。

## 4. 標的 (ポケット) 側

| ポケットの性質 | 誤差との相関 | |誤差| との相関 | 実測 pK との相関 |
|---|---|---|---|
| ポケット残基数 | **−0.386** | −0.123 | **+0.587** |
| ポケット原子数 | −0.357 | −0.106 | +0.598 |
| 疎水性残基の割合 | −0.128 | −0.081 | +0.195 |
| ポケット正味電荷 | +0.170 | −0.130 | −0.231 |
| 鎖数 | +0.032 | +0.094 | −0.048 |

ポケットの大きさ帯ごとのバイアス:

| 残基数 | ≤25 | 26-35 | 36-45 | 46-60 | >60 |
|---|---|---|---|---|---|
| n | 5 | 37 | 90 | 131 | 22 |
| バイアス | **+1.55** | +1.09 | +0.60 | −0.12 | **−0.46** |

**リガンドサイズのときと同じ単調な形**。ただしこれは独立な発見ではない:
**ポケットの大きさは実測 pK と +0.587 で相関しており、リガンドサイズ (+0.500) よりも
強い**。予測が平均に圧縮されている以上、pK と相関する変数はすべてこの形の
バイアスを示す。**ポケットサイズ固有の失敗ではない。**

**標的側固有かもしれない所見 — ただし確認できていない** (クラスタ単位、n=55):

| | 我々の ρ との相関 | GenScore の ρ との相関 | 差 (delta) との相関 |
|---|---|---|---|
| 疎水性残基の割合 | +0.138 | −0.148 | **+0.231** |
| 荷電残基の割合 | −0.145 | −0.092 | −0.013 |

疎水性 4 分位ごとの delta は単調 (−0.071 / −0.014 / +0.069 / +0.064) で、
**交絡には強い**: pk_spread / mean_pk / mean_heavy / pocket_res のどれで偏相関を
取っても +0.199〜+0.230 とほぼ動かない。Spearman も +0.219 で外れ値駆動でもない。

**しかし標本には弱い**: ブートストラップ 95% CI = **[−0.098, +0.503] で 0 を含む**
(P(>0) = 0.914)。さらに**ポケット性質を 7 個まとめて計算して報告している**ので、
n=55 で 7 個中の +0.231 は多重比較を考えると相当に弱い証拠である。

**§5 の分解能とは失敗の種類が違う**ことは記録しておく:
分解能は**切り方 (2.0Å) を結果を見てから選んだ**のが問題。
疎水性は変数を事前に決めて 7 個一括で出しているので切り方の恣意は無く、
純粋に標本数が足りない。前者は測り直しの設計が悪く、後者はセットが小さい。

## 5. 分解能 — 示唆的だが、**確認できなかった**

事前登録していない層別だったので確認を回した。**確認は取れなかった。**
以下は「示唆」として残すが、**主張として使ってはいけない。**

| 分解能 | n | 我々 R | GenScore R | 差 |
|---|---|---|---|---|
| **< 2.0 Å** | 162 | 0.775 | **0.833** | **−0.058** |
| **≥ 2.0 Å** | 121 | 0.777 | 0.776 | **+0.002** |

点推定だけ見ると「我々は分解能に対して平坦 (0.775 対 0.777)、GenScore は高分解能側で
伸びる (0.776 → 0.833)」という形で、量子化が微細幾何を捨てている仮説と一致する。

**しかしブートストラップ (5000 回、両群を独立に再抽出) では差の差が
−0.059、95% CI [−0.162, +0.045] で 0 を含む** (P(差の差 < 0) = 0.876)。
**n≈280 ではこの層別を支持も否定もできない。**

切り方を動かすと符号は一貫している (差の差は 1.8Å で −0.026、1.9Å −0.034、
2.0Å −0.059、2.1Å −0.079、2.2Å −0.036) ので、**方向としては疑う価値がある**。
だが 2.0Å という切り方が一番大きな差を出すのは、**結果を見てから切った**ことの
産物でもありうる。

交絡の確認: 2 群の pK の sd は 2.20 対 2.06 と近いので部分集合 R の比較自体は
素直に読める。ただし群は他の点で違う (重原子 23.5 対 26.0、ポケット残基 44.4 対 49.8)。

**結論: 未解決。** 決着させるには CASF-2016 の 285 件では足りず、
PDBbind test や CASF-2013 のような別セットで**事前登録した上で**測り直す必要がある。

## 6. 測定種 — おそらく独立な所見ではない

| 測定種 | n | バイアス | 我々 R | GenScore R | 差 |
|---|---|---|---|---|---|
| Kd | 107 | +0.61 | 0.719 | 0.773 | −0.054 |
| Ki | 178 | +0.06 | 0.805 | 0.822 | −0.017 |

Kd 側で差が 3 倍大きい。**ただし交絡がある**: Kd 複合体は平均 pK 5.92、
Ki は 6.82 と約 0.9 log 違う。我々の pK 帯別バイアス (5-6 帯で +0.85、6-7 帯で +0.31)
だけで観測された +0.61 対 +0.06 はほぼ説明できる。
**ポケットサイズのときと同じく、圧縮が相関変数を通して見えているだけ**の可能性が高い。
学習コーパスが Kd/Ki 両方を含んでいることとも整合しない (どちらも学習している)。
R の差 (尺度不変) だけは圧縮では説明できないので、ここは未解決として残す。

## 7. 効かなかった層別 (null)

- **登録年**: corr(年, |誤差|) = +0.034。年代による傾向なし。
- **鎖数**: corr(鎖数, |誤差|) = +0.094。界面ポケットでも壊れない。
- **タンパク質ファミリー別は測れていない**: CASF の `CoreSet.dat` の `target` 列は
  クラスタ番号であってタンパク質名ではなく、`data/casf2016/` に索引ファイルが無い。
  「キナーゼで負ける」のような主張は外部メタデータ (PDB/UniProt) を引かないと
  できないので、**していない**。分析の既知の穴として残す。

  corr(クラスタの重原子幅, 我々の ρ) = +0.106、GenScore +0.186。ほぼ無関係。

## 4. 必要な改善は 2 つ、別物

**(a) ranking → 分散を下げる。モデルを変える必要は無い。**
系統成分は既に GenScore と同等なので、**単一 run を平均の挙動に近づける**のが仕事。
8,150 文書に 99M encoder という比が分散の源なので、**独立ラベルを増やす**のが直行する手。
実際 H7 の汚染版では seed sd が 8 倍縮んだ (clean 版で検証中)。
これが再現すれば、**単一モデルのまま ρ 0.735 に届く**。

**(b) scoring → サイズ以外の信号を増やすしかない。他の道は塞がっている。**
再重み付けの天井が +0.0005 なので、**較正・正規化・efficiency 学習・サイズの
デコリレーションはすべて原理的に効かない**。残差を GenScore のものに差し替えると
R が 0.785 → 0.835 になるので、**欠けているのは重みではなく情報そのもの**。

埋めるべきは偏相関 0.698 → 0.772。**何が欠けているかは、この評価セットでは
特定できなかった。** 候補として極性相互作用の質 (H 結合の方向性、脱溶媒和)
と微細幾何の量子化損失の 2 つが挙がったが、**どちらも CI が 0 を含む** (§4, §5)。
**「サイズ以外の信号が 0.074 分足りない」ところまでは確実で、その中身は未特定**
というのが正直な到達点である。

**主指標を変えるべき**: 現在の R はサイズ由来が大半 (サイズ単独で R=0.500) なので、
改善の有無は **サイズを固定した偏相関** で見ないと、サイズへの寄りかかりが
増えただけでも R が上がってしまう。

分解能による層別は**この評価セットでは決着しなかった** (§5)。方向は
「トークナイザが微細幾何を捨てている」と整合するが、CI が 0 を含むので
codebook の細分化や残差量子化の価値をこの結果から見積もることは**できない**。
別セットでの事前登録した再測定が要る。

**優先順位**: (a) は走っている実験 (H7) で決まる。(b) は表現側の課題で、
4 日では届かない規模。**今回の締切では (a) を取り切り、(b) は
「どこが足りないか」を精密に特定した結果として報告するのが現実的。**
