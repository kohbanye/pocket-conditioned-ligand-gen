## 読み方の注意 (これは下限)

ノイズは等方・独立・無バイアスで、同じ大きさの誤差としては**最も優しい形**。
分子を平行移動も回転もさせず、局所幾何だけを崩す。実際の生成誤差はこの形を
していないので、**この曲線は「その誤差が最低いくら損か」の下限**。

もう一つ。曲線は「既知の最適点からどれだけ離れたか」を測っている。生成分子には
参照ポーズが無く、分子とポーズが同時に決まる。だから
「ProLIT の -1.72 は変位 0.79 A 相当」は *その分子自身の最適点からの距離* の
見積りであって、結晶ポーズからの距離ではない。

## 我々はどこにいるか

| | score | min | dock |
|---|---|---|---|
| 参照リガンド・結晶ポーズ | -6.61 | -6.79 | -7.66 |
| **ProLIT (実測)** | **-1.72** | **-4.37** | **-7.06** |
| FLOWR (論文値) | -6.29 | - | - |

**dock で見ると分子は足りている** (-7.06 は FLOWR の score -6.29 より良い)。
足りていないのは置き場所だけ。score -1.72 -> -6.29 に必要なのは
**変位を 0.79 A から 0.1-0.2 A 台へ、4-8 倍の精度向上**。

ここで効いてくるのが**トークナイザの下限**。参照リガンドの往復座標誤差は
RMSD 中央 0.344 A で、この曲線に載せると約 2 kcal/mol。つまり
**完璧な言語モデルでもこの codebook の上では届かない可能性がある**。

ただし等方ノイズと VQ 誤差は形が違う。予備測定 (6 標的) では
RMSD 0.37 の往復で score の損は約 1.1 kcal/mol にとどまり、同じ大きさの
等方ノイズ (2.08) の半分程度だった。VQ 誤差は構造化されていて結合長を
壊しにくいためと思われる。**全 100 標的での確定を
`tokenizer_vina_ceiling.py` で測定中** (job vqceil)。この数字が
「言語モデルを直すのか、トークナイザを直すのか」を決める。
