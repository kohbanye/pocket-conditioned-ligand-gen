# ProLIT が FLOWR に負けている理由 (2026-08-23 まとめ)

## 対戦成績 (99 標的、同一評価器・同一 receptor pdbqt・同一 Vina 設定)

| | ProLIT | FLOWR | ProLIT が勝つ標的 | p |
|---|---|---|---|---|
| Vina Score | -1.89 | **-5.63** | 10% | 7.1e-09 |
| Vina Min | -4.41 | **-5.93** | 21% | 5.9e-07 |
| Vina Dock | -6.98 | -7.21 | 44% | 0.11 |
| PB | 0.920 | **0.937** | | |
| clash-free | **0.964** | 0.866 | | |

**dock だけほぼ互角** (差 0.15、p は標的数で 0.02-0.11 の間を揺れる)。
dock は我々のポーズを使わないので、**分子は互角、負けているのは置き場所**。

## 損失の分解

| | kcal/mol |
|---|---|
| 参照分子・結晶ポーズ | -6.61 |
| 参照分子・VQ 往復 + refiner (= トークナイザの天井) | **-5.86** |
| FLOWR (実測) | -5.63 |
| 我々の分子が到達しうる上限 (= その dock) | -6.90 |
| **ProLIT (実測)** | **-1.89** |

**天井 (-5.86) は FLOWR (-5.63) より上。** トークナイザは越えを妨げていない。
残る 4 kcal/mol は全部言語モデル。

## 根本原因: アンカーがポケットを見ていない

| | 誤差中央 (A) |
|---|---|
| ポケットのトークン化精度 (空洞を囲む原子) | 0.27 |
| 学習なしの幾何式 (凹面重み付き重心) | **1.83** |
| ポケット非依存の定数予測 | 2.14 |
| **CLM の最初の原子 (正しいポケット)** | **2.13** |

**CLM のアンカーは、ポケットを一度も見ない定数予測器と同じ精度。**
情報は 0.27 A の精度でトークンに入っており、1 行の幾何式ですら 1.83 A を
出すのに、298M パラメータのモデルがそれを使っていない。

アンカーの誤差はそのまま分子全体に伝播する (原子 0 の広がり 2.37 A ->
重心の広がり 1.88 A、比 0.84、Spearman +0.74)。生成分子は
**サイズも形も正しく衝突もゼロなのに、2.1 A 隣に座っている**。

## 効かなかったもの (すべて測定済み)

自己回帰ドリフト / 誤差のカスケード / decoy 除去 / near-native fine-tune /
正準原子順 / 制約付きデコード / 記述子の自己整合性 / MLM による修復 /
腐敗学習した修復器 / ポケットの並び順 (distord) /
classifier-free guidance (学習前・学習後とも) / アンカー損失の重み付け /
フレーム原点の変更 / **幾何による選別 4 種** (衝突・PB・ポケット重心・
凹面重心) / **アンカー温度** / **補助ヘッド (centroid / anchor)** /
**正準原子順 (buried_first)**

**幾何による選別が 4 つとも失敗したのは一貫している**: 良し悪しを決めるのは
単純な幾何ではなくスコア関数の領分で、実際に効いたのは学習した rescorer
だけだった。

## 公平性 (確認済み)

- **ポケットの漏れは無い**: 訓練コーパス 16.5M 文書を全走査し、
  ベンチマーク 100 ポケットは 0 件。
- リガンドの再現は 8/100 (FLOWR は 0)。ただし**除外すると差はむしろ広がる**
  (+3.98 -> +4.04)。同じリガンドが別ポケットと組んで訓練に入っている
  ケースで、SBDD ベンチマーク共通の状況。
- 参照リガンドのサイズは使っていない (`min_atoms_frac` 既定 0)。
- FLOWR に当てたパッチ 2 件はどちらも生成内容を変えない。
- 固定していないのは**学習データ** (SPINDR vs CrossDocked2020)。
  これは実在する差で、表のキャプションに書くべきもの。
- Novelty は未測定 (`--train-smiles` の仕組みはあるがファイルが無い)。

## 原子順も却下 (2026-08-24)

規模をそろえたアブレーション (両方 196,839 doc、同一設定、学習完了):

| | アンカー中央 | 全原子中央 |
|---|---|---|
| file 順 | **2.390** | **1.832** |
| buried_first 順 | 2.688 | 3.448 |

アンカーは差なし (p=0.65)、全原子は **+88% 悪化**。定数予測の下限は
3.24 -> 1.28 A に下がるのに、モデルはそれを取りに行かない。

## 次にやるなら

診断が指しているのは**アーキテクチャ側で条件付けを強制すること**。
ポケットからリガンド重心を直接回帰する補助ヘッドを付け、その出力を
生成の条件にする。損失の重み付けでは足りなかった (p=0.40) のは、
勾配を増やしても「ポケットを読む経路」が生まれないため。

トークナイザの作り直し (residual VQ 等) は**後回しでよい**。天井は
FLOWR より上で、律速ではない。
