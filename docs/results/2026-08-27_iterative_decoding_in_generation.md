## probe と生成の落差が本質

| | 効果 |
|---|---|
| teacher-forced probe (RMSD) | 1.106 -> **0.780** (-29%) |
| 実生成 (Vina score) | -1.10 -> **-1.28** (-0.11) |

**probe は真の接頭辞を与えている。**つまり周りの原子は「正しい分子の正しい
位置」で、そこに 1 つだけ紛れた誤りを直す問題だった。生成では周り自体が
自己回帰のサンプルなので、「自信のない位置を直す」は**基準が無い**まま行われる。

PB と内部ひずみの悪化は結合ヘッドのときと同じ形
(`2026-08-25_bond_head_rejected.md`): **局所的に「より正しい」ものを入れても、
座標全体との自己整合が崩れれば分子は悪くなる。**MLM が数原子を動かすと、
自己回帰が組み立てた内部整合が壊れる。

## 主表での扱い

score だけを載せれば「有意に改善」だが、それは**不正**。
PB と dock を並べて、両方向を書く。FLOWR との差 4.6 に対して 0.11 は誤差。

## 残る問い

天井の測定 (真の未来で並べ替えると 1.070 -> 0.601、97.5% の分子で改善) は
**周りが正しい条件**での話だった。生成条件での天井は測っていない。
「自己回帰のサンプルを前提に、どこまで直せるか」が本当の上限で、
それは probe の 0.601 よりずっと手前にある可能性が高い。
