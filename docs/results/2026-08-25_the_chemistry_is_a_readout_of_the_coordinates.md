# 芳香性・drug-likeness の欠落は、化学の問題ではなく座標の問題 (2026-08-25)

## 見えていた症状

生成分子は FLOWR と比べて薬らしくない (`mlonly` 対 `flowr100`、
分子性質は SMILES から再計算):

| | 芳香環 | fsp3 | QED | SA | logP | Lipinski | uniqueness |
|---|---|---|---|---|---|---|---|
| ProLIT (ML のみ) | **0.0** | **0.94** | **0.348** | 4.10 | 0.42 | 0.775 | **0.597** |
| FLOWR | 2.0 | 0.49 | 0.517 | 3.70 | 1.37 | 0.916 | 0.990 |
| 参照リガンド | - | - | 0.468 | - | 1.09 | - | - |

**中央値の分子に芳香環が 1 つも無い。**fsp3 0.94 は糖やポリオールの領域で、
薬の分子ではない。

## データではない

学習コーパス (`lm_tokens_e250lig3_full`) のトークンを復号して同じ物差しで測った
(n=412):

| | 芳香環 | fsp3 | QED | 芳香環ゼロの分子 |
|---|---|---|---|---|
| **学習コーパス (復号後)** | **2.00** | **0.333** | **0.499** | 0.150 |
| ProLIT の生成 | 0.00 | 0.940 | 0.348 | ~0.60 |
| FLOWR | 2.00 | 0.490 | 0.517 | - |

**コーパスは FLOWR の出力とほぼ同じ化学をしている。**
トークナイザの芳香性ヘッドも正確
(再現率 0.960 / 適合率 0.988、`2026-08-21_aromatic_head_collapsed.md` の訂正)。

## 座標だった

化学ヘッド (element / charge / numH / aromatic) を**固定したまま**、
座標にだけ等方ノイズを足して、同じ復号経路を通す (n=500):

| sigma | 原子変位 | 芳香環 | 芳香環ゼロ | **分子になった割合** |
|---|---|---|---|---|
| 0.00 | 0.00 A | **2.00** | 0.124 | **0.712** |
| 0.25 | 0.43 A | **0.00** | 0.600 | **0.060** |
| 0.50 | 0.87 A | 0.00 | 1.000 | 0.004 |

**0.43 A の変位で芳香性は完全に消え、分子として成立する割合が
0.71 から 0.06 に落ちる。**

理由は経路にある。復号された原子は**距離から結合を知覚**される
(`infer_bonds`)。環が閉じなければ芳香環は無い。実測で、配備時の座標から
知覚した結合は真の結合との Jaccard 0.313、44% を落とし 63% を捏造し、
連結が完全一致する分子はゼロ。

(等方ノイズは同じ大きさの誤差として最も厳しい形で、結合長を直接壊す。
LM の誤差はもっと構造化されていて、実際の生成物は valid 0.994 で分子には
なっている。それでも機構は同じ。)

## 意味

**ProLIT が失っているもの — Vina score、PB-validity、芳香性、QED、
drug-likeness — は全部ひとつの欠陥から出ている。復号された座標。**

分子の同一性は座標から読み出されるので、座標が 2.5 A ずれていれば
距離は別の分子を語る。ポーズを直せば化学は付いてくる。

系の見立てが変わる: リファイナは Vina のための小細工ではなく、
**分子そのものを取り戻す部品**。

## 【訂正 2026-08-25】以下の打ち手は逆だった

実際にやってみると、**score だけ良くなって PB は 0.375 -> 0.034、
内部ひずみは 47 倍、dock は 98% の標的で悪化**した
(`2026-08-25_bond_head_rejected.md`)。

**化学が座標の読み出しである以上、結合グラフは座標と整合していなければ
ならず、読み出しだけを直すことはできない。**距離知覚が「近い原子しか
結ばない」のは弱点ではなく、生成された座標との自己整合性を保つ性質だった。

## そこから出る、学習の要らない打ち手

コードは既に element / charge / numH / aromatic / ring / hybrid を持っている。
それなのに結合グラフの出発点は**距離だけ**の `infer_bonds` で、
価数と芳香性はその後の枝刈りにしか使われていない。
**モデル自身が予測した化学を制約として使って結合を組む**ほうが、
壊れた座標に対してずっと頑健なはず。数値最適化ではなく、
モデルの出力の読み方の問題なので ML のみの比較の中に収まる。
