# リファイナは、存在しない誤差を直す訓練を受けていた (2026-08-23)

リファイナは測定上ただ一つ「効く」と確認できた部品 (VQ 往復ポーズで
-0.33 kcal/mol、61% の標的、p=0.026)。その学習時の腐敗が、実際に直すべき
誤差と合っているかを測った。

## 直すべき誤差の形

CLM の argmax コード列 (teacher forcing) を復号したものが、**ground truth の
分かっている、配備と同じ形の誤ったポーズ**になる。トークナイザ自身の
再構成を基準に取るので、トークナイザの誤差は二重計上されない。83 標的。

| | 中央 | 平均 | p90 |
|---|---|---|---|
| RMSD (全体) | 1.86 | 2.09 | 3.43 |
| **内部成分 (最適重ね合わせ後)** | **1.52** | 1.67 | 2.96 |
| 重心の並進 | 0.76 | 0.88 | 1.53 |
| 回転 (度) | 14.4 | 24.5 | 45.5 |

**分散の 65.6% が内部成分**、剛体は 34.4%。

## 学習時の腐敗

`refit_deploy` は `--online-jitter-sigma 0.3 --online-rigid-trans 1.45
--online-rigid-rot-deg 26.9`。コーパス側の既存の腐敗にこれが**足される**ので、
合成後の値で比べる (val 300 例):

| | 内部 | 並進 | 回転 | RMSD |
|---|---|---|---|---|
| コーパスのみ | 0.49 | 0.22 | 3.3 | 0.59 |
| **配備時の設定** | **0.70** | **2.16** | **19.5** | 2.82 |
| **実態 (CLM 出力)** | **1.52** | **0.76** | **14.4** | 1.86 |

**逆向きにずれている。** 内部ノイズは 2.2 倍**小さく**、並進は 2.8 倍**大きい**。
リファイナは「ほぼ剛体・内部ノイズ小」を直すよう訓練されているが、
実際の誤差は「ほぼ内部・剛体は中程度」。

これは `place_first` (剛体フィット) が生成ポーズで効く理由も説明する
(score -1.178 vs -0.978, p=0.036)。リファイナが過剰に想定していた剛体成分を
先に除いてやると、残りが訓練分布に近づく。

## 合わせた設定

`--online-jitter-sigma 0.85 --online-rigid-trans 0.42 --online-rigid-rot-deg 14.0`
で合成後が実態と一致する:

| | 内部 | 並進 | 回転 | RMSD |
|---|---|---|---|---|
| 提案 | 1.50 | 0.75 | 13.5 | 1.89 |
| 実態 | 1.52 | 0.76 | 14.4 | 1.86 |

`refit_matched` として学習中 (job refmatch)。

**測ってから決めること。** 1.45 / 26.9 / 0.3 という値は、どこかで
「妥当そう」に見えたのだろうが、直すべき誤差を測って決めたものではなかった。
