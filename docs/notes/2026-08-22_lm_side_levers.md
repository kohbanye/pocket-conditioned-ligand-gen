# LM 側で何が効いて何が効かないか (2026-08-22)

論文の主題はトークナイザと言語モデルなので、後処理ではなくそちら側の
打ち手を測った。まず**どこに損失があるか**を確定させてから当たった。

## 損失の分解 (正典 100 標的、10,000 分子)

3 つの Vina は測るものが違う。dock は再ドッキングなので**我々のポーズを
一切使わない** = 純粋に分子の質。標的ごとに参照リガンドと対で取ると:

| | 参照との差 (中央値) | 参照に勝った標的 |
|---|---|---|
| **dock** (分子だけ) | **+0.24** | **44.0%** |
| min (局所最適化後) | +1.88 | 13.0% |
| score (そのまま) | +4.44 | 2.0% |

**分子は悪くない。ポーズが 5.18 kcal/mol 失っている** (大域 2.68 + 局所 2.43)。

## トークナイザは律速ではない

参照リガンド 100 分子の往復 (符号化 -> 復号) 座標誤差:

| | A |
|---|---|
| RMSD 中央値 | **0.344** |
| p90 | 0.532 |
| 原子最大 中央値 | 0.624 |

LM のポーズ誤差は並進だけで中央値 0.71 A、**往復の 2.1 倍**。
`val/atom_coord` = 0.102 は正規化空間の値で A ではないので、これは測るまで
分からなかった。**表現は足りていて、誤差は LM が作っている。**

## 効かなかったもの

### コーパスの decoy 置換 (`clm_e250lig3_clean`)

decoy 80% を near-native + 結晶錯体に入れ替えた腕。val loss 5.3568 -> 3.7281
(perplexity 212 -> 41.6) と 30% 改善する。**生成は 3 つの Vina すべてで劣る**
(66 標的 / 6,600 分子):

| | PB | clash-free | score | min | dock |
|---|---|---|---|---|---|
| 現行 CLM | **0.927** | 0.958 | **-1.70** | **-4.34** | **-6.94** |
| clean CLM | 0.882 | 0.956 | -1.49 | -4.07 | -6.65 |

以前は clash で却下していた。今回 Vina で追試して、却下は正しかったと確認。
**val loss はポーズの正確さを測っていない**。decoy を抜くとユニーク SMILES が
706 -> 1081 に増え、当てにいく分布が広く難しくなる分、個々のポーズは甘くなる。

## 効きそうなもの: 原子の生成順

`LigandAtomDescriptor.compute` は `enumerate(atoms)` をそのまま使っていた。
つまり LM が原子を出す順は **SDF ファイルに書かれている順**で、並べ替えは
どこにも無かった。「次の原子」が空間的に何も意味しないので、モデルは既に
置いた原子との関係を学びようがない。

その代償が測れる。生成原子の衝突率を系列位置で見ると 0.041 -> 0.232 だが、
これは「後半の原子は外側にある」だけかもしれない。**重心距離を揃えて比べる**:

| 重心距離 | 系列前半 | 系列後半 | 比 |
|---|---|---|---|
| 0.1-2.5 A | 0.040 | 0.076 | **1.89x** |
| 2.5-3.7 A | 0.076 | 0.156 | **2.05x** |
| 3.7-5.1 A | 0.124 | 0.179 | 1.44x |
| 5.1-13.2 A | 0.175 | 0.236 | 1.35x |

同じ位置にある原子どうしで 1.35-2.05 倍。**分子中心付近で比が最大**なので、
位置では説明できない。自己回帰のドリフト。

対策として `atom_order="buried_first"` を実装した。ポケット重心に最も近い
原子から結合グラフを外向きに辿るので、**各原子は必ず既に置かれた原子と
結合している**。順序は分子とポケットの関数で、ファイルには依存しない。
トークン列が変わるので既存 checkpoint を壊す -- 既定は `file` のまま。

## サンプリング温度

40 標的 / 985 分子、後処理まで通した値:

| | PB | clash-free | 平均衝突 | ユニーク |
|---|---|---|---|---|
| t=1.0 | 0.9574 | 0.983 | 0.12 | 0.714 |
| t=0.85 | 0.9624 | 0.987 | 0.14 | 0.697 |
| t=0.7 | 0.9593 | **0.994** | **0.05** | 0.672 |

衝突は減り多様性は落ちる。差が小さいので Vina で判定する。

## 計測側で直したもの

- **Vina の失敗が 0.0 として記録されていた** (99/9,961 分子で 3 つとも厳密に 0、
  原子数中央値 30、衝突ゼロ)。中央値 -7 の列に 0 を入れると集計が歪む。
  失敗として扱うようにした。
- **リファイナの val に腐敗が適用されていなかった** (`if train else 0.0`)。
  2 A ずらされた分子を戻すよう学習したモデルに、ずれていない入力を渡していた。
  val RMSD 829 A を発散と誤読してリファイナを捨てた過去の判断は、これが根拠
  だった。両側に適用するよう修正したら 2.22 -> 1.79 A の学習曲線になった。
