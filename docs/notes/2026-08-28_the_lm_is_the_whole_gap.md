2026-08-28. 標的ごとに 1 つの代表値をとって揃えた比較（Vina score, 100 標的）。

- トークナイザが払う代償: **1.28 kcal**
- **天井 vs FLOWR: 0.11 kcal しか離れていない**
- **LM が残している伸びしろ: 4.49 kcal**

**完璧な LM ならこのトークナイザのままで FLOWR の中央値に並ぶ。**

**表現は律速ではない。** 今夜の実験を全部 LM 側に寄せているのはこの理由。

（注: 天井が「並ぶ」であって「勝つ」ではないことも同時に言っている。
トークナイザを直す価値が無いのではなく、**順番が後**というだけ。）

## 内部幾何を壊しているのは refiner だった (2026-08-28 06:45)

**同じ 9 標的**で対応をとった測定:

| | 結合長誤差 | >0.15A | 角<90度 | n_bond |
|---|---|---|---|---|
| **refiner なし** | **-0.019** | **8.6%** | 3.4% | 4141 |
| refiner あり (配備 `refit_press0.6`) | -0.118 | **47.2%** | 5.4% | 5097 |
| FLOWR | -0.019 | 4.7% | 0.7% | |
| 結晶 | -0.004 | 4.5% | 0.4% | |

**refiner を外すと ProLIT の内部幾何は FLOWR と同一になる (-0.019 vs -0.019)。**
トークナイザでも LM でもなく、**refiner が結合を 0.12 A 縮めている**。
MMFF ひずみ 998 vs 47 も、PoseBusters 0.43 vs 0.93 も、出所はここ。

### なぜ縮むか

`lambda_bond = 1.0` は既定で有効だが、**相対誤差の定式化では結合対が損失の
0.077 しか占めない** (config.py:220 の実測)。座標項に対して桁が足りず、
アンカーとして機能していない。**`lambda_angle` は既定で 0.0 = 完全に無効。**

学習時の腐敗は剛体並進なので x0 の結合長は最初から正しく、
bond 損失はほぼ勾配を生まない。配備では内部変形が入力なので、
flow-matching の変位場が平均へ回帰して分子が縮む。

### 打ち手 (投入済み)

```
--lambda-bond {10,30} --lambda-angle 5   (他は refit_press0.6 と同一)
```

`refit_geom_lb10` / `refit_geom_lb30`。gpu_1 10 h × 2 = **4 pt**。
狙いは **refiner の -0.87 kcal を保ったまま PB を 0.43 -> 0.85 に戻す**こと。

### 注意: これは「FLOWR に並ぶ」話ではない

refiner を直しても Vina score は -1.1 前後で、FLOWR の -5.68 には遠い。
**報告する数字が正直になる**という改善であって、gap を埋める話ではない。
gap 4.49 kcal は依然として LM 側にある（このファイル冒頭の表）。

### 取引の全体像 (同じ 60 標的)

| | 衝突率 <3A | 結合長誤差 | >0.15A |
|---|---|---|---|
| refiner あり (配備 = 対照) | **25.0%** | -0.118 | **48.1%** |
| **refiner なし** | **36.0%** | **-0.021** | **10.0%** |
| FLOWR | 9.7% | -0.021 | 4.5% |

**refiner は衝突を 36.0% -> 25.0% に下げるが、その手段が「分子を縮める」**
なので結合が 10.0% -> 48.1% 壊れる。両方とも同じ 1 つの操作の裏表。

### これで診断がいちばん綺麗になる

- **素のデコーダ出力: 化学は FLOWR と同一 (-0.021 vs -0.021)、配置だけが悪い
  (衝突 36.0% vs 9.7%)。**
- refiner: 配置を化学と交換しているだけで、正味の改善ではない。

つまり **LM の問題は「化学」ではなく「どこに置くか」** に完全に局在している。
トークナイザの天井が -5.60 (FLOWR -5.70 と同等) なのと整合する:
コードの語彙は足りていて、**選び方が配置を外している。**

`refit_geom_lb10/30` (`--lambda-bond 10/30 --lambda-angle 5`) が問うのは
**「縮めずに衝突を下げられるか」**。下げられるなら refiner は正味の改善になり、
下げられないなら refiner は主表から外すのが正直。

## refiner を外した結果 (暫定 6/8 シャード, 75 標的, 2026-08-28 08:44)

| 構成 | score | min | dock | **PB** | **strain** |
|---|---|---|---|---|---|
| ProLIT + `refit_press0.6` (配備) | **-1.26** | -4.76 | -7.42 | 0.424 | 699 |
| **ProLIT refiner なし** | **+5.19** | -4.19 | -7.34 | **0.733** | **197** |
| ProLIT + `refit_deploy` (press なし) | -0.44 | -4.83 | -7.42 | 0.401 | 745 |
| FLOWR | **-5.70** | | | **0.959** | **45** |

### refiner は 6.46 kcal 分の仕事をしている

既知の「-0.87 kcal」とは桁が違うが、**別の測定**なので矛盾ではない
(`2026-08-23_summary.md` のそれは配備誤差を与えた probe であって生成ではない)。
生成で外すと **score が -1.26 -> +5.19** になる。**正のスコア = 正味斥力**で、
素の LM 出力はポケットと重なっている (衝突率 36.0%、既測)。

### 正直な構図

- **素の LM 出力: 化学は上等 (PB 0.733 / strain 197)、立体は破綻 (+5.19)。**
- **refiner: 立体の破綻を化学の破綻に変換している** (PB 0.424 / strain 699 と
  引き換えに -1.26)。**正味の改善ではなく両替。**
- **FLOWR は両方同時に良い** (-5.70 かつ 0.959)。**どちらの端でも勝てない。**

`refit_deploy` は press0.6 より両方悪い (score -0.44, PB 0.401) ので、
配備の選択自体は正しかった。

### これが指すもの

トークナイザの天井は **-5.60** (FLOWR -5.70 と同等) で、
**天井に届く LM なら refiner は要らない**。
refiner は **LM の配置ミスを塗り潰すために存在している**。
だから refiner をどういじっても FLOWR には届かない。
**4.49 kcal は LM のコード選択にあり、そこ以外に無い。**

## lr 再学習の epoch 0（2026-08-29 18:20）: 仮説は支持されず（ただし未決着）

| | epoch 0 | epoch 1 |
|---|---|---|
| 配備 `clm_e250lig3_fullft` (lr 3e-4) | **5.3568** | 5.4648（悪化 -> early stop） |
| 新 `clm_e250lig3_ft_lr5e5` (lr 5e-5) | **5.7540** | 実行中 |

**lr を下げた方が epoch 0 は 0.40 悪い。**

### まだ決着していない理由

元の仮説は「**lr 3e-4 は epoch 0 の後に発散した**」であって
「epoch 0 が悪い」ではない。lr 5e-5 が単に収束が遅いだけなら、
epoch 1 で改善して追い越す可能性が残る。

**判定点は epoch 1**: 配備が 5.3568 -> 5.4648 と**悪化した**のに対し、
新しい方が**改善するか**。改善しなければ仮説は棄却で、
`fullft` e00 が最良という既存の結論が追認される。

20 h 枠で残り約 2 エポック。epoch 1 は 8/30 01:00 頃。

### 予算の扱い

この 1 本で 20 pt。epoch 0 の結果だけで打ち切ると
**仮説の肝（epoch 1 の挙動）を測らずに捨てる**ことになるので、
epoch 1 までは回す。epoch 1 で改善が無ければそこで止める。

## lr 仮説は棄却（2026-08-30 02:30、確定）

| | epoch 0 | epoch 1 |
|---|---|---|
| 配備 `clm_e250lig3_fullft` (lr 3e-4) | **5.3568** | 5.4648（悪化） |
| `clm_e250lig3_ft_lr5e5` (lr 5e-5) | **5.7540** | **5.8696（悪化）** |

**lr を下げても両エポックで悪く、e0 -> e1 の悪化パターンも同一。**
epoch 1 の劣化は lr のせいではなく、下げても防げない。

**「lr 3e-4 が高すぎた」は死んだ。** `fullft` e00 が最良という
既存の結論 (`2026-08-25_lm_checkpoint_is_already_the_best.md`) が追認された。

事前登録した判定点（epoch 1）で答えが出たので **epoch 2 を待たずに停止**。
残り約 5 h = 5 pt を節約し、コーパス側に回した。

### これが意味すること

**4.49 kcal の LM 側の伸びしろに、既知のレバーが 1 つも残っていない。**

潰した LM 側のレバー（このセッション + 過去）:
自己回帰ドリフト / 誤差のカスケード / decoy 除去 / near-native finetune /
正準原子順 / 制約付きデコード / 記述子の自己整合性 / MLM 修復 /
反復デコード 6 腕 / アンカー温度 / 補助ヘッド / classifier-free guidance /
幾何平滑化 CE / rescorer 選別 / **低 lr 再学習**。

残るのは**アーキテクチャか表現の変更**で、いずれも
「1 晩の改善ループ」の粒度を超える。
