# 事前登録: 学習した結合ヘッドを生成に入れる (2026-08-25)

## 何を変えるのか

生成経路の結合知覚を、距離 (`infer_bonds`) から**学習したヘッド**に替える。
1 変数だけの差分: リファイナは両方 `refit_deploy`、数値最適化は両方無し。

コーパス val (167 錯体) での結合グラフ復元:

| | Jaccard | 連結が完全一致 |
|---|---|---|
| 距離のみ (現行) | 0.309 | 0.000 |
| 順序のみ (i,i+1 を鎖に) | 0.377 | 0.000 |
| **学習したヘッド** | **0.733** | 0.162 |
| 結晶座標 (上限) | 1.000 | 0.898 |

## 腕

**訂正 (投入後に気づいた)**: 既測の `mlonly` は `gen100_noplace` を評価した
もので、リファイナが `refit_e250lig3` (e16)。`refit_deploy` ではない。
「1 変数だけの差分」にはなっていなかったので、**対照を別に生成する**。

| | リファイナ | 結合 | 数値最適化 |
|---|---|---|---|
| `mlonly` (既測、参考) | `refit_e250lig3` | 距離 | 無し |
| **`gen_dist_ml`** (対照) | `refit_deploy` | 距離 | 無し |
| **`gen_bond_ml`** | `refit_deploy` | **ヘッド** | 無し |

サンプリングは両方 seed 0 で LM も VQ も同じなので、**トークン列は同一**。
分子を index で対応させられるので、差は結合グラフだけになる。
判定は `gen_dist_ml` との対応のある差で行う (`mlonly` とではなく)。

## 主要評価指標と判定規則

**主要**: 標的ごとの Vina score 中央値、`mlonly` との対応のある差、
Wilcoxon p < 0.05。

**副次** (結果に関わらず報告。判定には使わない): PB-valid、clash-free、
vina min / dock、芳香環の数、fsp3、QED、uniqueness、valid。

## 予測 (結果を見る前に)

- **PB-valid と芳香性が最も動く。**分子の同一性はこのグラフから読み出される。
  PB-valid 0.618 -> **0.75 前後**、芳香環の中央値 0 -> **1 以上**、
  QED 0.348 -> **0.42 前後**と予測する。
- **Vina score は動くが小さい。**Vina は結合次数をほとんど見ず、
  原子の位置と型だけを見る。**-1 kcal/mol 未満**と予測する。
  座標は変わらないので当然。
- **vina dock は変わらない**と予測する (+-0.2 以内)。分子は同じ原子集合。
- uniqueness は**上がる**と予測する (0.597 -> 0.7 台)。今は壊れたグラフが
  別々の分子を同じ SMILES に潰している可能性がある。

**Vina score が 2 kcal/mol 以上動いたら、それは予測外。**
そのときは「結合が Vina に効く経路」を先に説明してから採用する。
