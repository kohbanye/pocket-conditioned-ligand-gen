# 生成タスク 改善計画 (2026-08-20)

## 診断の最終形: 「形状不適合」であって「剛体誤配置」ではない

衝突原子がどこにあるかを測って、以前の「約 2 A の剛体誤配置」という診断は
不正確だと分かった。

| | 全原子 | 衝突原子 |
|---|---|---|
| 重心からの相対距離 (0=中心, 1=最外殻) | 0.585 | **0.716** |
| 末端原子 (degree=1) の割合 | 24.8% | **39.8%** |

分子あたり衝突原子は中央値 7.7%。**中心はポケットに収まっており、外周・末端の
置換基が壁を突き抜けている。** 剛体変位なら全原子が均等に衝突するはずなので、
剛体較正は衝突の「量」は再現していたが「パターン」は違っていた。

化学は問題ない。参照リガンドとほぼ同等:

| 性質 | 生成 | 参照 |
|---|---|---|
| MW | 300 | 287 |
| logP | 0.17 | 0.97 |
| 環数 | 2 | 2 |
| **QED** | **0.46** | **0.46** |

したがって課題は **shape complementarity (形状相補性)** の一点。

## 3 指標は別々の要因で決まる

| 指標 | 律速 | 現状 | 参照 |
|---|---|---|---|
| Vina **score** | 衝突 (r=+0.914) | +2.97 | -5.43 |
| Vina **min** | binding mode | -4.29 | -5.55 |
| Vina **dock** | 分子サイズ | -7.02 | -6.89 |

* 衝突 0 の分子は score 中央値 **-2.44 / 92.4% が負**。衝突 <=1 にできれば
  score は負になる。
* **min は衝突数にほぼ依存しない** (-4.40 〜 -3.44)。衝突を消しても min は
  上がらない。別の問題。
* dock はサイズに単調増加するが QED は単調減少 (重原子 35 で dock -8.40 /
  QED 0.18)。**dock で勝つのは Vina のサイズバイアスを突くだけなので狙わない。**

## 改善案

### B-2: ポケットトークンの空間順序化 (LM 再学習のみ, 約 5 pt)

現状 `protein.py:191-197` は距離順に選抜した後 **配列順 (chain, residue index)
に並べ直している**。空間的近さが列順序に反映されていない。ポケット重心からの
距離順に並べれば RoPE の距離減衰が空間的近さと一致する。ポケット重心は受容体
だけから決まるのでリークにならない。

* 記述子は不変 -> **トークナイザ再学習が不要**
* 必要: 全コーパス再トークン化 + CLM 再学習
* 効果は**未検証の仮説**

### B-1: リガンド記述子にポケット近傍を入れる (トークナイザ再学習, 30-40 pt)

`_knn_offsets_and_elements` は渡された座標集合の中だけで近傍を取り、
`LigandAtomDescriptor.compute` にはリガンド原子しか渡らない。つまり
**リガンド原子は「自分の近くにどんなタンパク質原子があるか」を持っていない。**
空間的手がかりは正準フレームでの絶対座標のみ。

末端がはみ出して衝突しているという診断に対して、これが最も直接的な対処になる:
各リガンド原子が近傍タンパク質原子への相対ベクトルを持てば、はみ出しは
記述子の段階で検出可能になる。

* 記述子が変わる -> VQ-VAE 再学習 (18.3 pt) + 記述子キャッシュ再構築 +
  全コーパス再トークン化 + CLM 再学習 + 評価 = **30-40 pt**
* 33-D の内訳を変えるので `knn` を 4 近傍から減らして枠を作るか、次元を増やす
  かの設計判断が要る (次元増は論文の 33-D の主張に影響)

### C: ポケット体積による生成長制御 (約 1 pt) — 効果は限定的

ポケット外接箱体積とリガンド重原子数の相関は r = +0.477、線形予測の残差 SD は
7.7 重原子で元のばらつき 8.7 からほとんど減らない。**中央値は当てられない。**
ただしサイズ比 1.5 以上の 16% が clash-free 0.148 と突出して悪いので、
上限だけ設ける形なら clash-free +0.05 程度。B-2 のついでに入れる価値はある。

## 予算の現実

実測消費 約 66 pt / 残り 約 34 pt。

* B-2 + C: 約 6 pt -> **実行可能**
* B-1: 30-40 pt -> **残予算では収まらない**。B-2 の結果を見てから予算を追加
  するか判断するのが妥当。

## 推奨する順序

1. **B-2 + C を実行** (約 6 pt)。ablation として B-2 単独 / B-2+C を比較。
2. 効果が出れば B-1 に進む根拠になる (「空間情報を与えると効く」ことの証拠)。
   効果が出なければ B-1 も同じ理由で効かない可能性が高く、予算を投じる前に
   分かる。
3. B-1 は予算追加後。VQ 再学習 18.3 pt が最大の塊。

## 評価プロトコル (ablation)

同一の 97 標的 / 100 分子 / seed 0 / 標準優先度で以下を比較する。

| arm | ポケット順序 | サイズ上限 | 学習 |
|---|---|---|---|
| baseline | 配列順 | なし | 既存 `clm_e250lig3_clean` |
| B-2 | 距離順 | なし | 再学習 |
| B-2+C | 距離順 | あり | 再学習 (生成時のみ変更なので学習は共用) |

主要指標: clash-free, Vina score 中央値と負の割合, PB-valid。
副次: Vina min/dock, QED, SA, 多様性。
**dock は上げに行かない** (サイズバイアスのため)。
