# 記述子の 2 案はどちらもトークナイザを悪くした (2026-08-21)

生成分子の衝突を減らす狙いで、per-atom 記述子に 2 つの変更を試した。どちらも
VQ-VAE を 250 epoch 学習し直し、基準 `vq_e250_lig3` と同条件で比較した。

| arm | 変更 | best `val/atom_coord` | 基準比 |
|---|---|---|---|
| 基準 `vq_e250_lig3` | — | **0.10211** | — |
| **B-1** `vq_e250_pctx` | knn 4 枠のうち後半 2 枠をポケット原子に充てる | 0.10715 | **+4.9% 悪化** |
| **B-2** `vq_e250_distord` | ポケット残基をリガンドから近い順に並べる | 0.11620 | **+13.8% 悪化** |

どちらも exit 0 で完走 (18.4 h / 18.7 h)。数値は checkpoint の
`ModelCheckpoint.best_model_score` から読んだ。

## なぜ悪くなったか

**B-1**: knn 枠は有限で、2 枠をポケットに渡した分だけリガンド内部の近傍が
減る。局所幾何の情報が減れば座標再構成は落ちる。これは設計上の必然で、
問題は「ポケット情報がその代償に見合うか」だった。

見合わない。投入前の確認で、追加した記述子 (受容体接触枠の最小 Δr) は
衝突原子と非衝突原子を **中央値で +0.18 A** しか分離せず、最良の単一閾値でも
balanced accuracy **0.587**。ほぼ偶然と変わらない量の情報のために、座標を
4.9% 捨てたことになる。

**B-2**: 配列順は「隣接残基は結合している」という情報を持っている。距離順に
並べ替えるとそれが壊れ、encoder は主鎖の連結性を距離から推測し直すことになる。
悪化幅が B-1 の 3 倍近いのはそのため。

## 判断

どちらも採用しない。**採用したところで下流の LM を全部学習し直す必要があり、
その先に待っている利得を上の測定が否定している。**

衝突については、同じ日に別の答えが出ている:
`docs/notes/2026-08-21_pose_error_is_rigid.md` の剛体立体緩和は、学習を一切
伴わずに clash-free を 0.215 -> 0.871 にした。トークナイザに衝突回避を
学ばせるより、誤差が剛体であることを使うほうが桁違いに安い。

論文にはアブレーションとして両方載せる (「入れてみたが悪くなった」は
「入れなかった」より強い主張になる)。
