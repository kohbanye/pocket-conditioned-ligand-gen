## 主要評価指標と判定規則

**主要指標**: 標的ごとの Vina score 中央値。`mlonly` と**標的で対応を取った差**。

**判定**: 対応のある Wilcoxon で中央差 < 0 かつ p < 0.05 なら、
`refit_press0.6` を主表の配備リファイナとして `refit_deploy` を置き換える。
そうでなければ置き換えない。

**副次指標** (結果に関わらず報告する。判定には使わない):
clash-free 率、PB-valid 率、vina min、vina dock、Novelty、uniqueness。

## 予測 (外れたら外れたと書く)

原子ごとの項分解では repulsion が 7.50 (FLOWR 1.64) で、
score の差 6.86 kcal/mol のうち 5.9 がここにある。押し出しが効けば
score は **-4 から -5 の範囲**に入るはず。FLOWR の -5.73 には届かないと予測する。

**vina min の差 1.63 kcal/mol は press では消えないと予測する。**
局所最適化は既に押し出しをやっているので、min に残る差は
押し込みではなく別の原因 (内部配座か、置き場所そのもの) のはず。
ここが予測どおりなら、次の打ち手は押し出しではなくそちら。
