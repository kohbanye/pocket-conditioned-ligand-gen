# 事前登録: 反復デコードを生成に入れる (2026-08-27)

## 根拠

teacher-forced の probe (n=200) で、反復デコードが自己回帰を有意に上回った:

| 学習量 | 最良設定の差 | 改善した分子 |
|---|---|---|
| 9% | +0.326 | 23.5% |
| 15% | +0.031 | 47.0% |
| **~30%** | **-0.225** | **81.0%** |

最良は **rounds 2 / frac 0.05-0.1**。触る量を増やすほど悪化する
(f0.2 で -0.150、f0.5 で +0.890) ので、**自己回帰が一番自信のない数個だけを
直す**のが正しい使い方。

| | RMSD |
|---|---|
| 自己回帰 | 1.106 |
| 反復デコード (r2/f0.05) | **0.853** |
| 真の未来で並べ替え (天井) | 0.601 |
| VQ 往復 (下限) | 0.350 |

## 腕 (すべて ML のみ、100 標的)

差分は **1 変数だけ**。リファイナは両方 `refit_press0.6`、結合は両方距離、
数値最適化なし、seed も温度も同じ。

| | 反復デコード |
|---|---|
| `t=0.70` (既測) | 無し |
| **`gen_iter_ml`** | **`--mlm-ckpt ... --iter-rounds 2 --iter-frac 0.05`** |

## 主要評価指標と判定規則

**主要**: 標的ごとの Vina score 中央値、`t=0.70` との対応のある差、
Wilcoxon p < 0.05。

**副次** (結果に関わらず報告): vina min / dock、clash-free、PB-valid、
内部ひずみ、uniqueness、Novelty。

## 予測

- teacher-forced の RMSD が 1.106 -> 0.853 (23%減)。ポーズ精度曲線では
  **-0.5 から -1.0 kcal/mol** に相当すると予測する。
- **clash-free と PB が上がる**と予測する。ポーズが良くなれば repulsion が
  減り、結合知覚も座標から読むので改善するはず。
- **dock はほとんど動かない** (±0.2)。分子は同じ原子集合。
- **FLOWR の -5.73 には届かない**と予測する。現在 t=0.70 で -1.11 なので、
  -1 しても -2.1。天井 (VQ 往復 -5.60) までまだ遠い。

**予測が外れた場合**、特に score が -2 以上動いた場合は、
teacher-forced の probe と生成で条件が違う (probe は真の接頭辞を使う) ので、
どこで差がついたかを先に説明してから採用する。
