# 事前登録: サンプリング温度を ML のみの条件で測り直す (2026-08-25)

## なぜ今か

源流側の打ち手は 3 つとも潰れた (checkpoint 差し替え・追加 finetune・
幾何平滑化 CE)。リファイナでも戻せない (腐敗が可逆でない)。
残っているのは**サンプリングそのもの**。

teacher-forced argmax の誤差は RMSD 1.90 A。温度 1.0 の**サンプリング**は
それより必ず悪い。温度を下げれば argmax に近づくので、ポーズは良くなるはず。
**代わりに多様性を失う。**

過去に t0.7 / t0.85 は測ってあるが、**後処理 (MMFF + 剛体フィット) 込み**の
数字で、40 標的しかなく、ML のみの主表と比較できない。

## 腕 (すべて ML のみ、リファイナは `refit_press0.6`、100 標的)

| | 温度 | top-p |
|---|---|---|
| `press_ml` (既測) | 1.0 | 0.95 |
| `gen_t0.85_ml` | 0.85 | 0.95 |
| `gen_t0.7_ml` | 0.7 | 0.95 |

## 主要指標と判定規則

**主要**: 標的ごとの Vina score 中央値、`press_ml` との対応のある差、
Wilcoxon p < 0.05。

**同時に必ず報告する (これは判定を左右する)**: uniqueness と Novelty。
温度を下げれば score は良くなるが多様性を失うのは分かりきっているので、
**「score が良くなった」だけを報告するのは不正**。両方を 1 つの表に出す。

## 予測

- score は単調に良くなる。t0.7 で **-1 から -2 kcal/mol**。
- uniqueness は単調に落ちる。t1.0 の 0.60 から t0.7 で **0.45 前後**。
- dock はほとんど動かない (**±0.3 以内**)。分子の質の問題ではないので。
- **FLOWR の -5.73 には届かない**と予測する。argmax でも RMSD 1.90 A あり、
  ポーズ精度曲線ではそこが約 -3 kcal/mol の損に当たる。

**温度を下げて FLOWR に並んだ場合**、それは多様性を捨てて買った数字なので、
主表には uniqueness を並べたうえで「同等」とは書かない。
